# 会话工作台

这里放 **AI 会话的实时进度记录**：一次会话一份，回答「现在做到哪了、接下来干什么、卡在哪」。

**触发条件、命名规则与硬边界在项目规则里**（那份总是自动加载）。本文件只提供**文档模板**与人话说明。

## 模板（照抄）

```markdown
# 会话工作台 · <YYYY-MM-DD HH:mm> · <短ID>

> ⚠️ 一次性会话记录。只有创建它的那次会话会写它，其他会话请勿读取、请勿依赖。
> 需要长期事实看 `docs/`；需要历史沉淀看 AI 工具的长期记忆目录（如 `.workbuddy/memory/`）。

- **任务**：<一句话>
- **本轮状态**：进行中 | 等你确认 | 本轮完成
- **最后更新**：<时间>

## 现在在哪

## 接下来要做什么

## 卡住 / 等用户

---

## 流水账（只追加，最新在最下）
```

**上半部随进度反复改写**（「现在在哪」必须始终反映最新状态），**下半部只追加**。这样打开顶部三行就知道进展，不用翻历史。

## 给读这份文件的人

- 文件名里的 `<短ID>` 只用来防文件名撞车，**不代表任何身份**——每次会话都会变，别拿它认会话。
- **其他会话默认不需要读这里**：这些文件只对创建它的那次会话有意义。要长期事实看 `docs/`，要历史沉淀看 AI 工具的长期记忆目录。
- 文件**可以随时删**。删到只剩本 README 是正常状态——本文件常驻，兼作「目录不消失」的占位，免得别处指向 `worklog/` 的链接断掉。
- 「已结束」这种状态**不会有**：AI 拿不到「会话结束」事件，那种字段永远不会被写入。判断一次会话是否已经结束，看「最后更新」的时间戳。

## 一条给写作者的提醒

⚠️ 本目录**入库**，所以里面的工作台文档**不写 Markdown 相对链接**（路径一律用行内代码）——它们天生随时删改，写成链接会让链接自检脚本在别处报红。
