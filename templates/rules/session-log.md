# 会话工作台

**触发**：任务要动文件（写 / 改 / 删 / 跑改变状态的命令）就在动手**之前**建；纯问答与只读查看不建。

**文件名**：`docs/worklog/<YYYY-MM-DD>-<HHmm>-<短ID>.md`。短 ID 只为让文件名不撞车，**不代表任何身份**；没有现成随机串就自己生成 6 位小写十六进制。

**新建还是续写**：本次会话上下文里已有工作台内容 → 续写同一份；没有 → 新建。

**文档模板在 `docs/worklog/README.md`，照抄即可。**

## 只写三类东西

1. **意图** —— 接下来要做什么、为什么这么做
2. **结果** —— 做完了什么、结论是什么（一句话）
3. **阻塞** —— 卡在哪、在等谁

**凡是能从别处查到的事实，一律只写「去哪看」，不写内容本身。** 显式包括：**git 状态**（哪些已提交、commit 哈希、推送范围）、配置值、命令输出全文、文件清单。理由是单一信息源纪律——抄进来的派生事实必然会漂。

## 硬边界

- **不写 Markdown 相对链接**，路径一律行内代码——本目录入库，链接自检脚本会扫到它。
- 不记未决事项（→ `docs/todo/`），不记决策（→ `docs/adr/`）；与 `docs/` 冲突时以 `docs/` 为准。
- 其他会话**默认不读**本目录；**只写自己那一份**。
- **提交之后不再回填**——要补的内容等下一笔改动顺带带上。
- 收尾把「本轮状态」改成 `本轮完成`；整份没有实质记录就删掉它。
